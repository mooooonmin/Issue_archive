# Issue Archive

개발하면서 해결한 문제와 자주 쓰는 설정을 GitHub Issues에 모아 두는 레포입니다.

## 작성 방법

1. **New issue → 메모** 템플릿을 고릅니다.
2. 제목은 `[분류] 핵심 키워드` 형식으로 씁니다. 예: `[Flutter] 키스토어 생성과 릴리즈 서명`
3. **분류**에서 고른 값과 같은 이름의 라벨이 자동으로 붙습니다.
4. 정리가 끝나면 이슈를 닫습니다. 열린 이슈는 목차에 _(open)_ 으로 표시됩니다.

## 검색 팁

- 라벨로 찾기: `is:issue label:Flutter`
- 키워드와 함께: `is:issue label:Windows 포트`
- 본문에서만 찾기: `is:issue keystore in:body`

아래 목차는 이슈가 바뀔 때마다 GitHub Actions가 라벨별로 자동 생성합니다.
